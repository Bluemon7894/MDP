# Sindoh 3DWOX 2X DP303 3D 프린팅 가이드 (Slicer Guide)

본 문서는 **Sindoh 3DWOX 2X DP303** 3D 프린터를 사용하여 사탕 디스펜서의 6개 부품을 최적의 품질과 강도로 출력하기 위한 슬라이서 설정 및 부품별 배치 방향을 안내합니다.

---

## 1. 장비 사양 및 작업 공간 확인 (Printer Compatibility)

- **프린터 모델**: Sindoh 3DWOX 2X (DP303)
- **최대 출력 크기(Build Volume)**: **228 (X) × 200 (Y) × 300 (Z) mm**
- **노즐 사양**: 0.4 mm Dual Nozzle
- **본 설계 부품 규격 검증**:
  - 가장 큰 부품(`base_chassis` / `mid_housing` / `top_hopper`) 외곽 치수: **150 × 135 mm**
  - 높이: 최대 **95 mm**
  - **검증 결과**: 베드 안전 마진(Brim/Skirt 영역 포함 200 × 180 mm) 내에 완벽하게 수납되며, 듀얼 노즐 간섭 없이 단일 노즐 모드로 안전하게 출력 가능합니다.

---

## 2. 권장 슬라이서 프로파일 (Global Print Settings)

| 설정 항목 | 권장값 | 설명 및 이유 |
| :--- | :--- | :--- |
| **소재 (Filament)** | **PLA** 또는 **PETG** | 치수 정밀도가 우수하고 수축/휨(Warping)이 적음 (식품 접촉부에는 투명/순정 소재 권장) |
| **노즐 직경 (Nozzle)** | **0.4 mm** | 기본 표준 노즐 |
| **레이어 높이 (Layer Height)**| **0.20 mm** | 출력 시간과 디테일의 최적 균형 (드럼은 0.16mm 권장) |
| **초기 레이어 높이** | **0.25 mm** | 베드 밀착력 극대화 |
| **내부 채움 (Infill)** | **20% ~ 25%** | 패턴: **Gyroid** 또는 **Grid** (기계적 강도 및 토크 지지) |
| **벽 두께 (Wall Lines)** | **3 ~ 4 라인 (1.2 ~ 1.6 mm)**| 나사산 자체 태핑 및 조립 강도 확보 |
| **상/하단 레이어 (Top/Bottom)**| **4 ~ 5 레이어 (0.8 ~ 1.0 mm)**| 바닥 및 천장 면 평탄도 보장 |
| **노즐 온도** | PLA: 200 ~ 210°C / PETG: 235 ~ 245°C | 슬라이서 기본 프로파일 준수 |
| **베드 온도** | PLA: 55 ~ 60°C / PETG: 70 ~ 75°C | 열변형 방지 |
| **출력 속도** | 외벽: 40 mm/s, 내부/인필: 60 mm/s | 치수 공차(0.35mm) 정확도 유지 |

## 3. 부품별 최적 출력 배치 및 서포트 가이드

| 부품 STL 파일 | 베드 배치 방향 (Orientation) | 서포트 (Supports) | 예상 출력 시간 (0.2mm 기준) |
| :--- | :--- | :---: | :---: |
| **`drum_dispenser.stl`** | **원통 축을 수직으로 세워 배치** (피벗 보스가 바닥을 향하도록) | 최소 (포켓 상단 브릿징에 부분 생성) | 약 2.5 ~ 3.5시간 |
| **`base_chassis.stl`** | **바닥면이 베드에 밀착**되도록 수평 배치 (Z=0) | 포트 개구부 부분에만 터치다운 서포트 | 약 5.5 ~ 7.0시간 |
| **`mid_housing.stl`** | **하단 결합면이 베드에 밀착**되도록 수평 배치 | 드럼 원통 챔버 상단부에 서포트 생성 | 약 6.5 ~ 8.0시간 |
| **`top_hopper.stl`** | **하단 결합면이 베드에 밀착**되도록 수평 배치 | 호퍼 내부 경사각(>45°)은 서포트 없이 자립 출력 가능 | 약 4.5 ~ 5.5시간 |
| **`top_lid.stl`** | **상단 평평한 돔 면이 바닥**으로 가거나 리드가 위를 향하도록 배치 | **서포트 불필요 (0%)** | 약 1.5 ~ 2.0시간 |
| **`service_panel.stl`**| **패널 평면이 베드에 수평 밀착**되도록 배치 | **서포트 불필요 (0%)** | 약 1.2 ~ 1.8시간 |
| **`drum_bearing_cap.stl`**| **바깥쪽 평평한 면이 베드에 수평 밀착**되도록 배치 | **서포트 불필요 (0%)** | 약 25 ~ 35분 |

## 4. Sindoh 3DWOX 슬라이서 출력 팁

1. **베드 레벨링 (Bed Leveling)**:
   - 본체 바닥 면적이 150 × 135 mm로 넓으므로, 출력 전 3DWOX 2X의 자동 침대 레벨링(Bed Leveling)을 실행하여 첫 레이어 들뜸을 방지하십시오.
2. **사탕 두께 변수 조정 (config.scad)**:
   - 사용자가 사탕의 실측 두께를 측정한 후 두께가 13mm보다 두껍거나 얇을 경우, `cad/config.scad` 파일의 `candy_thickness = 13.0;` 값을 수정한 뒤 `python render_all.py`를 실행하면 모든 부품이 자동으로 재계산되어 업데이트됩니다.
