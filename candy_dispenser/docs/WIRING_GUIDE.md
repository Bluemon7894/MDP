# 배선 및 전원 구성 가이드 (라파 5V 올인원 단일 전원 방식)

본 문서는 **Raspberry Pi 5**와 **ULN2003 드라이버 보드**, **28BYJ-48 스테퍼 모터(5V)**를 추가 외장 전원 없이 **라즈베리파이 5의 5V GPIO 핀에서 직접 올인원으로 전원을 공급받는 깔끔한 6가닥 직결 구성**을 설명합니다.

---

## 1. 라즈베리파이 5 직접 전원 공급 원리

* **28BYJ-48 모터 소모 전류**: 약 150mA ~ 200mA (0.2A 수준)
* **라즈베리파이 5 전원 용량**: 공식 5V 5A (27W PD) 전원 사용 시, 40핀 헤더의 5V 레일에서 최대 1.6A 이상을 넉넉하게 공급할 수 있습니다.
* **결론**: 별도의 외부 5V 전원선이나 보조배터리를 따로 연결할 필요 없이, **라즈베리파이 5의 5V/GND 핀에서 모터 드라이버 전원을 바로 공급**받아 단일 전원으로 가장 심플하게 구동할 수 있습니다.

---

## 2. 전체 배선 구성도 (System Schematic)

```text
[Raspberry Pi 5 보드 (5V 5A Type-C 전원)]
  - 물리 Pin 2 (5V 전원) -------------------------> [ULN2003 드라이버 보드]
  - 물리 Pin 6 (GND 접지) ------------------------>   - VCC (5V 입력)
                                                      - GND (접지)
  - 물리 Pin 11 (GPIO 17) ------------------------>   - IN1
  - 물리 Pin 12 (GPIO 18) ------------------------>   - IN2
  - 물리 Pin 13 (GPIO 27) ------------------------>   - IN3
  - 물리 Pin 15 (GPIO 22) ------------------------>   - IN4
                                                          |
                                                      [5핀 흰색 소켓]
                                                          |
                                                   [28BYJ-48 모터]
```

---

## 3. 상세 핀 연결 매핑 (암-암 점퍼선 딱 6가닥)

| 연결 순번 | 라즈베리 파이 5 핀 번호 | BCM GPIO 이름 | ULN2003 핀 | 설명 | 권장 전선 색상 |
| :---: | :--- | :--- | :--- | :--- | :---: |
| **1** | **물리 Pin 2** (또는 Pin 4) | **5V Power** | **VCC** | 모터 구동용 5V 전원 직결 | 빨간색 |
| **2** | **물리 Pin 6** (또는 Pin 9) | **GND** | **GND** | 전원 및 신호 기준 접지 | 검은색 |
| **3** | **물리 Pin 11** | `GPIO 17` | **IN1** | 스테퍼 코일 상 A 제어 | 노란색 / 주황색 |
| **4** | **물리 Pin 12** | `GPIO 18` | **IN2** | 스테퍼 코일 상 B 제어 | 노란색 / 주황색 |
| **5** | **물리 Pin 13** | `GPIO 27` | **IN3** | 스테퍼 코일 상 C 제어 | 노란색 / 주황색 |
| **6** | **물리 Pin 15** | `GPIO 22` | **IN4** | 스테퍼 코일 상 D 제어 | 노란색 / 주황색 |

* 28BYJ-48 모터의 5핀 케이블은 ULN2003 보드의 흰색 5핀 소켓에 방향대로 꽂기만 하면 끝납니다.

---

## 4. 직결 시 안전을 위한 소프트웨어 수칙 (완료됨)

라파에서 직접 모터 전원을 끌어쓸 때 유일하게 주의할 점은 **"모터가 돌지 않고 대기할 때 코일에 전류가 계속 흐르지 않게 차단하는 것"**입니다.
* 본 프로젝트의 제어 코드([`dispenser.py`](file:///c:/Users/User/Desktop/학교/2학년/MDP/cat.io/candy_dispenser/src/dispenser.py))는 모터가 1회 회전한 직후 즉시 4개 GPIO를 모두 LOW(`0, 0, 0, 0`)로 떨어뜨려 대기 전류를 0으로 만듭니다.
* 따라서 모터와 라파에 발열이 일절 발생하지 않고 24시간 안전하게 운용됩니다.
