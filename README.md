# 내가 대충 그린 낙서, AI는 얼마나 맞힐 수 있을까?

Google Quick, Draw! 인식 모델로 그림을 맞히는 두 화면짜리 드로잉 아케이드 게임입니다.
제시어를 그리면 AI가 그림을 보고 무엇인지 추측하고, 맞힌 순위와 속도·획 수·구도로 점수를 매깁니다.
모드는 혼자 하기, 둘이 대결(두 화면 동시), 반쪽 협동, AI와 대결 네 가지입니다.

## 주요 기능

### 1. 그림 인식
- 제시어는 Quick, Draw! 범주 중 276개(한글 이름)에서 무작위로 10개를 뽑습니다.
- 획을 256×256 상자에 맞춰 정규화하고, 0°/90°/180°/270°로 돌린 그림을 함께 보내 눕혀 그린 그림도 알아보게 했습니다.
- 획을 그을 때마다 AI가 떠올린 후보를 오른쪽 'AI 판정' 칸에 보여 주고, **완성**을 누르거나 20초가 지나면 마지막 획까지 확인한 뒤 채점합니다.
- 인식 점수는 Quick, Draw! 95% + 친구들이 그린 손그림(코사인 유사도) 5%로 섞습니다. 인터넷이 안 되면 친구 손그림만으로 판정합니다.
- 지우개로 지운 선은 AI가 보는 그림에서도 빠집니다.

### 2. 두 화면
- 두 화면 사이 메시지는 개발 서버(Vite)의 WebSocket으로 주고받아서 다른 기기에서도 이어집니다. 서버 없이 정적 배포하면 같은 브라우저 안에서만 `BroadcastChannel`로 대신합니다.
- 화면은 주소의 `?screen=` 으로 고릅니다.
  - `?screen=a`: 1P 화면 (홈, 모드 선택, 1P 플레이)
  - `?screen=b`: 2P·랭킹 화면 (평소에는 명예의 전당, 2인 모드에서는 2P 플레이)
  - `?screen=both`: 개발용, 한 화면을 반으로 나눠 둘 다 보기

### 3. 손글씨 이름 입력
- 이름을 손으로 쓰면 Google 필기 인식(한국어)으로 읽어 1순위 후보를 넣고, 다른 후보도 고를 수 있습니다.

### 4. 채점 (라운드당 1000점)
- AI 인식 300: 제시어가 몇 순위 후보였는지 (1위 / 2~3위 / 4~5위)
- 속도 250: 인식된 그림을 완성했을 때 남은 시간 비율 (20초 기준)
- 획 수 250: 3~8획일 때 만점, 너무 적거나 많으면 감점
- 구도 200: 화면 대비 크기와 가운데 배치
- AI가 알아보지 못하면 획 수·구도 점수는 절반만 인정합니다. 반쪽 협동은 두 사람이 나눠 그린 정도와 이음새로 배율을 곱합니다.

### 5. 명예의 전당
- 모든 게임 기록은 서버의 `data/history.json`에 쌓이고, 이름마다 최고 기록으로 Top 10을 뽑습니다 (`localStorage`는 캐시).
- 1~3위 시상대, 전체 기록 관리(이름 수정·삭제·초기화)가 있습니다.

### 6. AI 차례 그림
- AI와 대결에서 AI는 `src/img/ai/`의 연필 소묘를 붓질로 드러내며 그립니다. 같은 제시어에 그림이 여러 장(`<제시어>--2.jpg` …) 있으면 그중 하나를 무작위로 고릅니다.
- 소묘는 Wikimedia Commons 사진에서 물체만 오려 연필 소묘로 바꾼 것이고, 출처·저작자·라이선스는 [`src/img/ai/SOURCES.md`](src/img/ai/SOURCES.md)에 있습니다.
- 소묘가 없는 제시어는 친구들이 그린 선화, 그것도 없으면 Quick, Draw! 낙서로 그립니다. 배경이 남았거나 잘린 그림은 `src/img/ai/_rejected/`로 빼 두었습니다.

### 7. 사탕 디스펜서 (라즈베리 파이 5)
- 28BYJ-48 5V 스텝 모터(64:1 감속) + ULN2003 드라이버, 라즈베리 파이 5의 5V 핀(Pin 2, Pin 6)에서 전원을 받습니다.
- 모터가 멈추면 제어 핀 4개를 바로 꺼서 대기 중에는 전류가 흐르지 않습니다.
- 게임이 끝나면 점수에 따라 `POST /dispense`로 사탕을 0~4개 배출합니다 (사탕 1개 = 드럼 1회전).
  - 혼자 하기: 1,000점 이상 1개 · 3,000점 이상 2개 · 5,000점 이상 3개
  - AI와 대결: AI를 이기면 3개, 지면 혼자 하기 기준
  - 반쪽 협동(팀 점수): 1,000점 이상 2개 · 3,500점 이상 3개 · 5,500점 이상 4개
  - 둘이 대결: 1,000점 넘은 사람마다 1개 + 높은 점수가 3,000점·5,000점을 넘으면 1개씩 (최대 4개)
  - 사탕 서버 주소는 1P 화면이 접속한 서버 주소의 `:8080`입니다. 다르면 브라우저 `localStorage`의 `DISPENSER_HOST`에 IP를 넣으세요.
- 3D 프린팅 부품은 `candy_dispenser/stl/`, 조립·배선·출력 안내는 `candy_dispenser/docs/`에 있습니다.

## 사용 기술

- React 19 + Vite, TypeScript, Tailwind CSS
- HTML Canvas (PointerEvent, 펜 필압·터치)
- Google Quick, Draw! / 필기 인식 (inputtools), 친구 손그림 16×16 격자 특징
- Python 3 HTTP 서버 + 라즈베리 파이 5 GPIO (`candy_server.py`)

## 배선

| 라즈베리 파이 5 핀 | GPIO | ULN2003 핀 | 역할 |
|---|---|---|---|
| Pin 2 | 5V | VCC | 모터·드라이버 전원 |
| Pin 6 | GND | GND | 공통 접지 |
| Pin 11 | GPIO 17 | IN1 | 코일 A |
| Pin 12 | GPIO 18 | IN2 | 코일 B |
| Pin 13 | GPIO 27 | IN3 | 코일 C |
| Pin 15 | GPIO 22 | IN4 | 코일 D |

배선은 표 순서대로 꽂습니다. 코드(`candy_server.py`의 `PINS = [17, 27, 18, 22]`)가 가운데 두 핀을 바꿔 IN1→IN3→IN2→IN4 순으로 구동해 28BYJ-48의 코일 순서를 맞춥니다 ([WIRING_GUIDE.md](candy_dispenser/docs/WIRING_GUIDE.md) 참고).
모터만 시험하려면 `python3 candy_server.py --test` 로 사탕 1개 배출 동작을 돌려 봅니다.

## 시작하기

### 준비물
- [Node.js](https://nodejs.org) 20 이상
- 라즈베리 파이 5 (사탕 디스펜서를 쓸 때) 또는 일반 PC
- 인터넷 연결 (Quick, Draw! 인식)

### 설치 (처음 한 번)
```bash
git clone https://github.com/Bluemon7894/MDP.git
cd MDP
npm install -g pnpm
pnpm install
```

### 라즈베리 파이에서 서버 실행
```bash
chmod +x start.sh
./start.sh
```
게임 서버(`http://<파이 IP>:5199`)와 사탕 서버(`:8080`)가 함께 켜집니다. 노트북 두 대로 1P·2P 화면을 엽니다.

### PC에서 실행
```bash
start.bat
```
한 PC에 모니터 2대로 쓰려면 `start-arcade.bat`를 실행합니다.

### 화면 주소
| 화면 | 주소 |
|---|---|
| 1P 화면 (홈·게임) | http://<서버 IP>:5199/?screen=a |
| 2P · 랭킹 화면 | http://<서버 IP>:5199/?screen=b |

- 한 컴퓨터 + 모니터 2대: `start-arcade.bat` → 두 화면이 각 모니터에 전체 화면으로 뜹니다. 모니터 배치가 다르면 파일 안의 `MONITOR2_POS`를 고치세요.
- 노트북 2대: 서버를 켠 기기에서 `start-arcade.bat a`, 다른 노트북에서 `start-arcade.bat b 서버IP`.
  - 다른 기기에서 안 열리면 Windows 와이파이를 "개인 네트워크"로 바꾸거나 방화벽에서 Node.js를 허용하세요. 학교 와이파이는 기기끼리 통신을 막을 수 있어 휴대폰 핫스팟이나 공유기가 확실합니다.

### 기록
- 랭킹·전체 기록·홈 그림은 서버의 `data/` 폴더에 저장됩니다 (GitHub에는 올라가지 않음).

### 라즈베리 파이용 CSS (화면을 고쳤다면 꼭)
- 라즈베리 파이에서는 Tailwind를 직접 돌리면 멈춰서 미리 만든 `.prebuilt/index.css`를 씁니다. 파이가 서버이면 노트북 화면도 이 CSS를 받습니다.
- 화면 코드에 새 Tailwind 클래스를 쓰면 PC에서 아래 명령으로 다시 만든 뒤 함께 커밋해야 파이에서 스타일이 보입니다 (안 하면 버튼이 안 눌리거나 색이 빠질 수 있음).
```bash
pnpm css:prebuilt
```
